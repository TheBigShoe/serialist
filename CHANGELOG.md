# Changelog

All notable changes to Serialist are recorded here, newest first. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/) (before 1.0, a minor version may break things).

To cut a release, rename "Unreleased" to the version and date and start a new empty
"Unreleased" above it. `docs/releasing.md` has the steps, and the release workflow
publishes the version's section as the draft release's notes.

## [Unreleased]

- Added: 4, 6, 8 and 12 Mbaud in the standard baud lists (the port settings popover, Settings' default baud and its device profiles), for FTDI FT232H and FT2232H class adapters. The no-dropped-bytes gate moves from 3 to 12 Mbaud: tests run a simulated firehose at 1.2 MB/s through the virtual link, a session in both directions and the ingest thread into the store, with an opt-in 60 s soak (`--test soak`) and an opt-in loopback on a real adapter (`--test hardware`, `SERIALIST_HW_PORT`).
- Fixed: a `buffer_font_size`, `ui_font_size`, terminal `font_size` or line height too large or small for a 32-bit float (such as `1e300`) loaded as infinity or zero; it is now rejected with its position, like other bad values. Found by the new `config_jsonc` fuzz target.
- Added: the Fadetouched theme family by Arishawke (MIT, https://github.com/Arishawke/fadetouched-theme) is bundled: Fadetouched and Fadetouched Blur, dark teal-green (Serialist does not blur windows, so Fadetouched Blur differs from Fadetouched only in its translucent surface colors over an opaque window), picked in Settings' Appearance section or by name in `theme`. Its copyright and license text are in the new `THIRD_PARTY_LICENSES.md`, which the macOS, Linux and Windows packages now include.
- Added: four more bundled themes, picked in Settings' Appearance section or by name in `theme`: Serialist Ember (warm charcoal, amber accent), Serialist Phosphor (green CRT), Serialist Paper (warm off-white, teal accent) and Serialist Contrast (pure black, every text color it sets at 7:1 or more, for bright labs and projectors).
- Fixed: adding, removing or dragging a device profile in Settings rewrote the whole `devices` array in `settings.json` and dropped the comments in it; each now changes that profile only, and a dragged profile takes the comments written with it.
- Fixed: a tab's monitor or VT mode was forgotten at quit; it is kept in `state.json` (now version 2, and version 1 files still load) and restored with the tab.
- Fixed: the Settings Keymap list left out the saved commands' keybindings; they are listed as "command" rows (filterable by action, group, chord or "command"), and Rebind… on one sets the command's `keybinding` in its collection instead of writing `keymap.json`.
- Fixed: with the Settings tab in front the status bar said "No session"; it keeps showing the session you came from (port, state, counters), or "Settings" with the config folder when none is open.

## [0.1.0] - 2026-10-01

Nothing has been released yet. What exists so far, one line per milestone of `docs/plan.md`:

- Milestone 0, toolchain and shell: the workspace, CI and license policy, the session engine with reader and writer threads, real serial transport with hotplug port discovery, a simulated-device world (`--virtual`), and a GPUI shell that shows a device's output.
- Milestone 1, performance core: a page-store scrollback with O(1) append, the monitor-mode ANSI parser, an ingest thread, a GPU terminal element with search, selection, hex view, pause, export and raw recording, plus criterion benches and frame-cost gates.
- Milestone 2, configuration: JSONC settings with Zed's key names and per-device profiles, Zed theme and keymap loading (Serialist Dark and Serialist Light and per-platform default keymaps are bundled), font settings with fallback, and a debounced watcher that applies changes live.
- Milestone 3, interaction modes: inline interactive typing (a configurable Backspace and escape chord, paced paste), a compose bar and saved commands with a Commands panel, expected replies and persistent history, local-time timestamps and dim control-character glyphs.
- Milestone 4, scripting: a Lua 5.4 script host on its own thread, a Script console and Scripts menu, a watched scripts folder with two example scripts, script payloads in saved commands, `on_connect` device hooks, and a headless `--script` run that exits 0, 1 or 2.
- Milestone 5, plugins: the `Codec` trait and frame store, Airoha RACE and text-line codecs in Rust, Lua plugins (`plugin.lua` folders), WebAssembly plugins (`plugin.wasm` and `plugin.toml`, WIT v1, the `serialist-plugin-sdk` guest crate and an Airoha RACE example) behind the off-by-default `wasm` feature, a simulated RACE device, and tests that hold all three RACE codecs to identical output.
- Decoders are plugins you install: no codec is built in or active by default (the Rust RACE and text-line codecs are test references only). The Airoha RACE plugin ships as an example, installed with "Install example plugin: Airoha RACE" in the command palette or the codec menu, which copies it into `plugins/airoha-race/`; the codec menu and the Decoded rail icon appear once a plugin is installed. A device profile naming a missing plugin connects without a codec and offers to install it, its Devices chip is greyed, and a codec command without its plugin is not sent.
- Milestone 6, started: CI on macOS, Linux and Windows (plus a job for the `wasm` feature), and release packaging: a macOS `.app` in a `.dmg`, a Linux `.tar.gz` and `.deb` (no AppImage), a Windows `.msi`, and a workflow that turns a `v*` tag into a draft GitHub Release. Release builds are unsigned. Tabs: a tab per open port (repeatable `--port` and `--virtual NAME`), background tabs that keep ingesting, recording and scripting without drawing, tab keys (`cmd-t`, `cmd-w`, `cmd-1` to `9`, `cmd-shift-]`/`[`; Disconnect moves to `cmd-shift-w`), and the open tabs restored at start (`state.json`, the `restore_session` setting). A port settings popover (framing, flow control, line ending, echo, live DTR and RTS, Send break) in the session toolbar and on each Devices row, and Disconnect and Connect buttons that reconnect into the same scrollback. Full terminal emulation: VT mode (`terminal.emulation`, a device profile's `emulation`, `alt-v` or the toolbar) shows a terminal screen fed next to the scrollback store, sized to the pane, with its cursor, cursor key mode, bracketed paste, title on the tab, bell on the status dot and query answers; search, export and recording keep reading the log, and Export adds the screen. `virtual:menu`, a boot menu device, is a built-in. The chrome, redesigned: a one-row icon toolbar with shortcut tooltips, an Export menu, a codec menu and an overflow menu for what does not fit; docks with icon rails that fold below 1100 and 900 px and keep their widths in `state.json`; 28 px rows throughout, hover actions on Devices and Commands rows and a folding "Simulated" group; a 24 px status bar with byte rates and chips; a command palette (`cmd-shift-p`); and framed bytes hidden by default while a codec decodes.
- A Settings screen (`cmd-,`, the Serialist menu's Settings…, the palette) in a tab beside the sessions, as a front end to `settings.json` and `keymap.json`: appearance, terminal font, display, session, device profiles (a form built on the port settings), the keymap with Rebind…, and plugins. Each change writes one key through the comment-preserving editor and the watcher applies it; defaults and project-set keys are marked, a rejected value is never written, and a broken file shows its error.
- A new app icon, "Pulse S": the letter S drawn as one oscilloscope trace, a UART frame (idle line, start edge, data bits, stop bit) running into a bright beam spot, on a deep navy tile. It replaces the chevron-and-signal mark of the first packaging work (kept as `packaging/icons/classic.svg`) in the macOS `.icns`, the Windows `.ico`, the Linux hicolor PNGs and scalable SVG, and the README. The 16 and 24 px sizes come from a variant with a tighter glow (`packaging/icons/serialist-small.svg`) so the S stays clear in a title bar or a Finder list.
